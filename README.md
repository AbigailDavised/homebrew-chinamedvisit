# homebrew-chinamedvisit

Official isolated Homebrew Tap for **chinamedvisit.com**.

## Installation

```bash
brew tap AbigailDavised/chinamedvisit
brew install chinamedvisit-cli
```

## Quick Start

```bash
chinamedvisit-cli --help
```

## Capabilities & Architecture
- Direct terminal client connecting to official MCP streamable HTTP endpoint: `https://chinamedvisit.com/api/mcp`
- Zero sign-in, zero tracking, stateless calculations
- Website: https://chinamedvisit.com
